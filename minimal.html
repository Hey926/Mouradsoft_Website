Introduction

Small enough for the edge, structured enough for automation.

Mubuntu Minimal is the stripped-down Mouradsoft distribution for headless devices, CI runners, container nodes, and controlled workstation bases. It ships a minimal userspace, a tuned kernel profile, and a local repository API so provisioning scripts can inspect updates before applying them.

Distro Features

The default surface is intentionally narrow.

Ultra-small footprint Minimal package set with only boot, network, shell, and service primitives.
Minimal kernel Lean kernel profile tuned for edge hardware, containers, and predictable boot.
Repository API Local hooks expose package lists, kernel updates, and node statistics.
GET

/minimal/v1/repository

Query the configured Mubuntu Minimal repository mirror for package, kernel, and system state before starting an unattended update.

Request Parameters

Field Type Required Description
channel string Required Repository channel: stable, testing, or edge.
arch string Optional Target architecture. Defaults to the local system architecture.
include_stats boolean Optional Include CPU, memory, uptime, and package cache statistics.

Response Parameters

Field Type Description
packages array Available package names, versions, and repository origins.
kernel_update object Current kernel, available kernel, and reboot requirement.
system_stats object | null Optional local node statistics when requested.

Status Codes

Code Meaning Resolution
200 Repository metadata returned successfully. Proceed with package selection or staged updates.
400 Invalid channel, architecture, or query parameter. Correct the request and retry.
401 Missing or invalid local repository token. Enroll the node token before requesting metadata.
500 Local repository service failed. Inspect service logs and retry after recovery.
